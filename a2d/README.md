# a2d — ZIP/RARの展開

bit7z 4.1.0を通じて`7z.dll`を直接使用します。`7z.exe`の子プロセスを起動せず、DLLを一括処理につき1回だけ読み込みます。

```powershell
a2d.exe "archive.zip" "archive.rar"
a2d.exe --dll "D:\Tools\7-Zip\7z.dll" "archive.zip"
```

## 配置と失敗時の動作

- 出力はアーカイブと同じ場所の、拡張子を除いた名前のフォルダです。
- 展開結果が単一ルートフォルダだけなら、その中身を配置します。例: `book.zip`内の`root/a.txt` → `book/a.txt`。
- 複数のルート項目はそのまま配置します。既存の出力先には結合・上書きしません。
- アーカイブの隣に専用の一時フォルダを作成し、全展開が成功してからディレクトリの移動で確定します。CRC不一致などの失敗時に、不完全な出力を正式名で残しません。
- `.scr`は大文字・小文字を区別せず全階層で展開対象から除外し、展開後にも除外漏れを確認します。
- 展開前に項目情報を調べ、絶対パス・親参照・不正なパス、Windows上で大文字小文字だけが異なる重複名、リンク・リパースポイントを拒否します。Unix形式のZIPリンク属性も検査します。
- 暗号化された保持対象項目は拒否します。パスワード入力の待機は行いません。
- 空アーカイブや除外後に項目がない場合は失敗します。空フォルダの展開には対応します。
- 元アーカイブは保持します。失敗後も後続の入力を処理し、1件以上の失敗で終了コード1を返します。
- 失敗時は一時フォルダを削除します。削除できない場合は残ったパスを報告します。強制終了時には一時フォルダが残ることがあります。
- ZIP、RAR4、RAR5が対象です。自己解凍RARは対象外、分割RARは未検証です。

## DLLの設定

実行ファイルとDLLのアーキテクチャを合わせてください。x64版にはx64の`7z.dll`が必要です。検索順序は次のとおりです。

1. `--dll`で明示したパス
2. 実行ファイルの隣の`a2d.pref`の1行目
3. 実行ファイルの隣の`7z.dll`
4. `C:\Program Files\7-Zip\7z.dll`

`a2d.pref`はUTF-8（BOMあり・なし）とWindowsコードページに対応します。旧設定の`7z.exe`パスは同じ場所の`7z.dll`へ読み替えます。明示したパスが存在しなければエラーになります。

```text
D:\Tools\7-Zip\7z.dll
```

## ビルドとテスト

VS2026のC++デスクトップ開発、Windows SDK、CMake 3.24以上が必要です。初回はbit7zと7-Zip SDKの取得にネット接続が必要です。bit7zのバージョンと取得ファイルのSHA-256はCMakeで固定しています。

```powershell
powershell -File a2d\build.ps1 -Configuration Release -Platform x64
powershell -File a2d\test-a2d.ps1 -Exe a2d\out\build\x64\Release\a2d.exe
```

`a2d.vcxproj`は同じスクリプトを呼ぶMakefileプロジェクトです。ソリューションから通常ビルド・リビルドできます。実行時の`7z.dll`は別途配置してください。

回帰テストは日本語・空白のパス、単一ルート解除、再帰的SCR除外、既存出力保護、失敗後の継続、ZIP/RARのCRC不一致、全項目除外、空フォルダ、親参照、重複名、RAR4の内容・元ファイル保持、旧pref移行、Unix形式のZIPリンクを確認します。テストは専用フォルダ内のコピーと生成データだけを操作します。

## 検証・速度比較（2026-10-09）

VS2026のRelease x64ビルド・リビルド、Debug x64ビルドが成功しました。回帰テスト14ケースが成功しています。別途、libarchiveの圧縮RAR4・ソリッドRAR5で、展開した全4ファイルずつのSHA-256が7z.exeの展開結果と一致しました。パスワード付きZIPの拒否も確認しました。

直前のexe版とDLL版を同じMSVC 14.51のRelease相当（`/O2 /MD /std:c++20`）で比較しました。7-Zip 19.00のexe/DLLを使用し、テキスト2ファイルを含む小さなアーカイブ30個を1回の起動で展開しました。入力生成は計測外、起動・展開・検査・確定は計測内です。3回の中央値を示します。各回で全出力ファイルの内容一致を確認しています。

| 入力30個 | exe版 | DLL版 | 速度比 |
|---|---:|---:|---:|
| 圧縮ZIP | 1.049秒 | 0.235秒 | 約4.5倍 |
| 格納RAR4 | 1.041秒 | 0.397秒 | 約2.6倍 |

小さなアーカイブでは外部プロセス起動の削減が効きます。大容量・高圧縮率の入力で同じ倍率になることは保証しません。複数アーカイブの並列展開は導入していません。
