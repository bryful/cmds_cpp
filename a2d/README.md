# a2d

ZIP/RARを安全に新しいフォルダへ展開します。7-Zipが必要です。

```
a2d.exe archive.zip archive.rar
```

## 配置と失敗時の動作

- 出力先は常にアーカイブと同じ場所の、拡張子を除いた名前のフォルダです。
- 展開結果が単一ルートフォルダだけなら、その中身を出力先へ配置します。例: `book.zip`内の`root/a.txt` → `book/a.txt`。
- 複数のルート項目はそのまま配置します。例: `book.zip`内の`a.txt`と`b.txt` → `book/a.txt`と`book/b.txt`。
- 旧版で親ディレクトリへ直接展開していたケースも、アーカイブ名のフォルダへ展開します。
- 出力先が既に存在すれば失敗します。既存フォルダへの結合や上書きはしません。
- 同じ親ディレクトリ内に専用の一時フォルダを作成し、7-Zipが終了コード0を返してからディレクトリの移動で配置します。一覧取得は行いません。
- `.scr`は大文字・小文字を区別せず全階層で除外します。展開後にも除外漏れを確認します。
- 展開結果のリンク・リパースポイントは配置しません。
- 失敗時は一時フォルダを削除します。削除できない場合は残ったパスを報告します。強制終了時には一時フォルダが残ることがあります。
- 空アーカイブや、除外後に項目がなくなったアーカイブは失敗として扱います。空フォルダの展開には対応します。
- 元アーカイブは保持します。1件でも失敗すると終了コード1を返し、後続の入力は処理します。

## 設定

既定の7-Zipは`C:\Program Files\7-Zip\7z.exe`です。実行ファイルと同じ場所の`a2d.pref`の1行目で変更できます。UTF-8（BOMあり・なし）と従来のWindowsコードページに対応します。空・無効な設定は既定値へ戻します。

## ビルドとテスト

Visual Studioのx64 Native Tools環境で実行します。

```
msbuild a2d\a2d.vcxproj /p:Configuration=Release /p:Platform=x64
powershell -File a2d\test-a2d.ps1 -Exe x64\Release\a2d.exe
```

テストはスクリプトと同じ場所に専用フォルダを作成し、テスト用ZIPと実行ファイルのコピーのみを操作します。日本語・空白を含む名前、単一ルート、SCR除外、既存出力、失敗後の継続、CRCエラー、除外後の空結果、空フォルダの8ケースを確認します。

## 検証記録（2026-10-09）

MSVC 14.51のx64直接ビルド（`/O2 /MT /W4 /std:c++20 /utf-8`）と、PDB生成を検証時だけ無効化したRelease x64のMSBuildが成功しました。両方の実行ファイルで回帰テスト8ケースが成功しています。プロジェクト既定のPDB生成設定は変更していません。この環境では前の検証でPDB DLLの不一致が発生しています。

ローカルの7-Zip 19.00とZIPで検証しました。RARの実ファイル、パスワード付きアーカイブ、リンクを含むアーカイブの動作は未検証です。並列展開は導入していません。

小さいテキスト2件を含む同一ZIPを30個コピーし、旧版と新版をそれぞれ一括処理しました。旧版も同じMSVCの`/O2 /MT /std:c++20`でビルド。コピーは計測外、起動・展開・配置は計測内、標準出力は破棄しています。

| 版 | 1回目 | 2回目 | 3回目 | 中央値 |
|---|---:|---:|---:|---:|
| 旧版 | 2.022秒 | 3.261秒 | 1.637秒 | 2.022秒 |
| 新版 | 1.676秒 | 0.750秒 | 0.725秒 | 0.750秒 |

中央値では約2.7倍の速度でした。キャッシュ等による変動が大きく、小さいZIPに限った測定です。大容量ZIP/RARの速度改善率を示すものではありません。安全性向上に伴う一時フォルダ作成と展開後走査も新版の計測に含みます。
