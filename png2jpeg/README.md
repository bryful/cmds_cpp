# png2jpeg

Windows x64用のPNG→JPEG変換コンソールアプリです。品質90で、透明部分を黒背景に合成して保存します。

```text
png2jpeg.exe [path] [-nodelete] [-overwrite]
```

```powershell
png2jpeg.exe
png2jpeg.exe "C:\画像"
png2jpeg.exe "C:\画像\sample.png" -nodelete
png2jpeg.exe "C:\画像\image_?.PNG" -overwrite
```

- パス省略時はカレントディレクトリ、ディレクトリ指定時はその直下のPNGすべてが対象です。サブディレクトリは処理しません。
- ファイル指定時はそのPNGのみ処理します。ファイル名の `*`（任意の文字列）と `?`（任意の1文字）に対応し、大文字・小文字は区別しません。
- 出力は同じ場所の同じベース名で、拡張子は `.jpeg` です。
- **保存成功後に元PNGを削除します。** `-nodelete` を指定すると保持します。
- 出力が存在する場合はスキップし、次へ進みます。`-overwrite` を指定すると上書きします。
- 変換や保存に失敗した場合、元PNGを保持して次へ進みます。元PNGの削除だけに失敗した場合は、完成したJPEGとPNGが残ります。
- 複数フレームのPNGは先頭フレームのみ変換します。

日本語・空白を含むパスに対応します。空白やワイルドカードを含むパスは引用符で囲んでください。標準出力・標準エラー出力はUTF-8です。

設定ファイルは使用しません。書き込み中は出力先ディレクトリに一時ファイルを作成し、通常は処理後に除去します。強制終了などで残った `.png2jpeg-*.tmp` は、アプリが動作していないことを確認して削除できます。

失敗時には対象パスと理由を表示します。書き込み・削除権限や、ほかのアプリでファイルを開いていないか確認してください。終了コードは正常終了（スキップ・対象なしを含む）が0、処理失敗が1、引数エラーが2です。

追加の画像処理DLLは不要です。実行には対応するMicrosoft Visual C++ x64ランタイムが必要です。本リポジトリの[MIT License](../LICENSE)に従います。
