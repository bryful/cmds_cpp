# fs — 角括弧による振り分け・逆移動

```powershell
fs.exe "C:\Downloads"
fs.exe -r "C:\Downloads"
```

通常モードは直下のZIP/RARを、ファイル名の最初の`[...]`内の文字列を使って振り分けます。拡張子の大文字・小文字は区別しません。例: `[作者]作品.zip` → `作者\[作者]作品.zip`。

`-r`は直下の各サブフォルダのファイルを1階層上へ移動します。ZIP/RAR以外も対象です。下位フォルダには再帰しません。移動によって空になったサブフォルダだけを削除し、最初から空だったフォルダは残します。`-rev`、`/r`、`/rev`も使用できます。

引数省略時は通常モードで現在の作業フォルダを処理します。フォルダ名が`-`で始まる場合は`.\-folder`のように指定してください。逆モードの入力もフォルダに限定しています。

## 安全性と終了コード

- 通常・逆モードのどちらも、移動先に同名項目があれば失敗します。既存ファイルを上書きせず、元ファイルを残します。
- 移動は置換を許可しないWindows APIで実行します。移動先を調べてから上書きする方式ではありません。
- 振り分け先の`.`・`..`、末尾の空白・ドット、区切り文字・不正文字、Windows予約名は拒否します。
- 入力直下にあるジャンクションやシンボリックリンクなどのリパースポイントはスキップします。振り分け先がリンクの場合はエラーです。明示した入力パスやその祖先にディレクトリリンクがある場合も拒否します。
- 1件の失敗後も、処理できる残りの項目を続けます。移動・スキップ・失敗の件数を表示し、1件以上の失敗で終了コード1を返します。
- 存在しない入力、フォルダ以外の入力、引数の不足・余分な引数も終了コード1です。
- ファイルの内容は変更しません。リンクのスキップ、対象外拡張子、角括弧のない名前は失敗件数に含めません。

## 実装と検証

パスをWindowsネイティブの文字列で扱い、ファイルごとの正規表現生成とUTF-8への往復変換を取り除きました。列挙結果を保持してから移動するため、列挙中のフォルダ変更による取りこぼしを避けます。専用の中間ディレクトリを使い、旧プロジェクトの生成物との混在も避けています。

VS2026でビルドできます。x64はv145、Win32は既存のv143設定です。7-Zipなどの外部ツールは不要です。

```powershell
msbuild cmds_cpp.slnx /t:fs:Rebuild /p:Configuration=Release /p:Platform=x64
powershell -File fs\test-fs.ps1 -Exe x64\Release\fs.exe
```

回帰テストは専用フォルダ内の生成データだけを操作します。正常な日本語名の振り分け、不正な振り分け先、通常・逆移動の衝突、移動先がファイル、逆移動・通常移動先・入力ルートのジャンクション、不正入力、逆移動後の空フォルダ削除、下位フォルダ・既存空フォルダの保持、ロックされた入力の12ケースを確認します。ジャンクションを作成できる環境が必要です。テスト終了時はリンク自体を先に削除してから専用フォルダを片付けます。
