# d2z

フォルダの中身を、同じ場所の新しいZIPへ圧縮します。7-Zipが必要です。

```
d2z.exe C:\images
d2z.exe --fast C:\images C:\documents
d2z.exe --store C:\already-compressed
d2z.exe -- -folder
```

## 圧縮モード

- 通常実行: 7-Zipの既定のZIP圧縮設定を維持します。
- `--fast`: `-mx1`による高速圧縮。圧縮率は入力によって変わります。
- `--store`: `-mx0`による圧縮なしのZIP作成。
- モード指定は一括処理全体に適用します。同時指定・重複指定はエラーです。
- `--`以降はすべてフォルダ名として扱います。

## パスと安全性

- `images`、`images\`、絶対パスのいずれも、フォルダの隣の`images.zip`へ出力します。ドライブのルートは受け付けません。
- ZIP内のパスは圧縮対象からの相対パスです。入力で指定した親フォルダ名は格納しません。
- 入力直下に項目が1つだけあり、それがフォルダなら、その中身を圧縮します。この従来の動作は維持します。判定は1回の列挙で行います。
- 既存ZIPは更新・上書きしません。出力が存在する場合は失敗します。再作成する場合は既存ZIPを移動するなどして出力先を空けてください。
- 入力と同じ親ディレクトリの専用一時フォルダに、新規のZIPを作成します。
- 読めない入力があれば7-Zipの`-sse`で処理を失敗させます。終了コード0、出力ファイルの存在、フラッシュ・close成功を確認してから、置換を許可しない移動でZIPを確定します。
- 失敗時は一時フォルダを削除します。削除できなければパスを報告します。強制終了では一時フォルダが残ることがあります。
- 元フォルダは保持します。失敗があっても後続入力を処理し、1件でも失敗すると終了コード1を返します。
- 空フォルダは空のZIPとして作成します。圧縮中に元ファイルが変更される場合のスナップショット保証はありません。

## 7-Zipの設定

既定は`C:\Program Files\7-Zip\7z.exe`です。実行ファイルと同じ場所の`d2z.pref`の1行目で変更できます。UTF-8（BOMあり・なし）と従来のWindowsコードページに対応します。無効な設定は既定値に戻ります。

## ビルドとテスト

Visual Studioのx64 Native Tools環境で実行します。

```
msbuild d2z\d2z.vcxproj /p:Configuration=Release /p:Platform=x64
powershell -File d2z\test-d2z.ps1 -Exe x64\Release\d2z.exe
```

テストはスクリプトの隣の専用フォルダに入力と実行ファイルのコピーを作ります。相対パス・末尾区切り・日本語名、単一サブフォルダ、階層保持、既存ZIP、ロックされた入力、失敗後の継続、空フォルダ、圧縮モードの8ケースを確認します。通常・高速・圧縮なしのZIPに対して7-Zipの整合性検査も行います。

## 検証記録（2026-10-09）

MSVC 14.51のx64直接ビルド（`/O2 /MT /W4 /std:c++20 /utf-8`）と、PDB生成を検証時だけ無効にしたRelease x64のMSBuildで動作を確認しました。両方のビルドの回帰テスト8ケースが成功しています。最終のclose結果確認を追加したコードはMSBuildで検証しました。プロジェクトの既定のPDB生成設定は維持しています。

ローカルの7-Zip 19.00を使用。テキスト約4.29MBとシード固定の疑似乱数4MiBを別のフォルダへ作成し、新版の各モードを3回実行しました。入力作成は計測外、プロセス起動・圧縮・フラッシュ・ZIP確定・一時フォルダ削除は計測内、標準出力は破棄しています。同じMSBuild版の実行ファイルによる比較です。

| モード | 1回目 | 2回目 | 3回目 | 中央値 | ZIPサイズ |
|---|---:|---:|---:|---:|---:|
| 通常 | 186ms | 175ms | 246ms | 186ms | 4,210,173バイト |
| --fast | 135ms | 140ms | 139ms | 139ms | 4,210,173バイト |
| --store | 50ms | 54ms | 55ms | 54ms | 8,484,586バイト |

このデータでは高速モードが約26%の時間短縮でした。実際の画像・動画・多数の小ファイルでは結果が変わり、すべての入力での速度・圧縮率を保証しません。並列圧縮は導入していません。
