# ディレクトリ調査ツール（dircount・dirsize・dirFind・findGFile）

Windows向けのディレクトリ調査用コマンドラインツール集です。ファイル数の集計、ファイルサイズの集計、ファイル名の検索、大容量ファイルの検索を行います。

## ツール一覧

| ツール | 用途 |
| --- | --- |
| `dircount.exe` | 各ディレクトリ直下の通常ファイル数を集計し、多い順に表示 |
| `dirsize.exe` | 各ディレクトリ直下の通常ファイルのサイズを合計し、大きい順に表示 |
| `findGFile.exe` | 指定サイズ以上のファイルのフルパスを再帰的に検索 |
| `dirFind.exe` | ファイル名に指定文字列を含む通常ファイルを再帰的に検索 |

パスはUnicodeに対応し、結果はUTF-8で出力します。

## 実行環境と起動

Windows向けのコンソールアプリです。findGFile.exeはWindows x64に対応します。以下の例は、実行ファイルのあるディレクトリをPowerShellで開いて実行する想定です。

## ファイル数の集計

```powershell
.\dircount.exe [path]
.\dircount.exe "C:\Data"
```

`path` を省略するとカレントディレクトリを対象にします。指定したルート配下のディレクトリを再帰的に走査し、それぞれの直下にある通常ファイル数を表示します。

出力例：

```text
0012  /photos
0003  /documents
0000  /documents\archive
```

数値は最低4桁のゼロ埋めです。同数の場合はパス順に並びます。ルート自体の行とルート直下のファイルは集計に含みません。子ディレクトリ内のファイル数を親に加算する処理もありません。

## ファイルサイズの集計

```powershell
.\dirsize.exe [path]
.\dirsize.exe "C:\Data"
```

`path` の扱いと走査範囲は `dircount.exe` と同じです。各ディレクトリ直下の通常ファイルのサイズを合計し、降順に表示します。同サイズの場合はパス順に並びます。

出力例：

```text
     1.50 GB  /photos
   24.00 KB  /documents
         0 B  /documents\archive
```

単位は `B`、`KB`、`MB`、`GB`、`TB` で、1024を基準に切り替えます。子ディレクトリのサイズは親に加算しません。表示するのはファイルの論理サイズで、ディスク上の占有サイズではありません。

## ファイル名の検索

```powershell
.\dirFind.exe "search string" [path]
.\dirFind.exe "report" "C:\Data"
.\dirFind.exe "ä" "C:\Data"
```

検索文字列は必須です。検索パスを省略するとカレントディレクトリを対象にします。ルート直下を含む通常ファイルを再帰的に検索します。

検索対象はファイル名だけです。ファイル内容や親ディレクトリ名は検索しません。WindowsのUnicode対応APIを使用し、大文字・小文字を無視して部分一致を調べます。ワイルドカードや正規表現には対応していません。

出力例：

```text
/documents/report.txt
/documents/archive/REPORT-2025.pdf
```

一致したファイルのルートからの相対パスを、走査順に表示します。検索結果のパス区切りには `/` を使用します。

## 大容量ファイルの検索

指定サイズ以上のファイルを、サブディレクトリも含めて検索します。

```powershell
.\findGFile.exe [パス] [-size MByte]
.\findGFile.exe
.\findGFile.exe "D:\Data"
.\findGFile.exe "D:\Data" -size 500
.\findGFile.exe -size 2048
```

パスを省略するとカレントディレクトリを検索します。ルート直下とサブディレクトリの通常ファイルが対象です。既定は1024MByte以上で、1MByteは1,048,576バイトです。`-size`は0以上の整数で指定し、0では空ファイルも対象になります。判定するのはファイルの論理サイズです。

該当ファイルのフルパスを標準出力へ1行ずつ出力します。サイズの数値や見出しは付けません。

標準出力の例：

```text
D:\Data\backup.zip
D:\Data\動画\recording.mp4
```

スキャン中のディレクトリのフルパスは標準エラー出力へ表示します。

```text
Scanning: D:\Data
Scanning: D:\Data\動画
```

パスに空白が含まれる場合は二重引用符で囲んでください。日本語を含むパスに対応し、出力はUTF-8です。結果と進捗ログは次のように分けて保存できます。

```powershell
.\findGFile.exe "D:\Data" -size 500 > files.txt 2> scan.log
```

アクセスやサイズ取得に失敗した場合は理由とパスを標準エラー出力へ表示し、検索可能な範囲で継続します。終了コードは正常時0、引数不正や検索中のエラー時1です。一致がなくても正常終了します。ディレクトリのシンボリックリンクやジャンクションなど、ディレクトリの再解析ポイントのリンク先には再帰しません。ただし検索ルートとして直接指定したパスは開きます。

設定や検索履歴は保存しません。リダイレクト先以外にファイルを書き込みません。対象パスが見つからない場合やアクセスが拒否された場合は、パスとアクセス権を確認してください。

## 出力と終了コード

- 検索・集計結果は標準出力に出力します。
- 進捗、走査件数、エラーメッセージは標準エラー出力に出力します。
- 終了コード `0` は正常終了です。検索で一致するファイルがなくても `0` です。
- 引数や対象パスの不備、ディレクトリを開けない場合、列挙中のエラー、サイズ取得エラーでは終了コード `1` を返します。

エラー発生時には途中までの結果が出力されることがあります。自動処理では、結果だけでなく終了コードも確認してください。アクセス拒否はエラーとして扱います。

PowerShellで結果とログを別々に保存する例：

```powershell
.\dircount.exe "C:\Data" > counts.txt 2> scan.log
$LASTEXITCODE
```

## リンクの扱い

すべてのツールで、通常ファイルを指すシンボリックリンクはファイルとして検索・集計される場合があります。

- `findGFile.exe`：ディレクトリのシンボリックリンク、ジャンクションなど、ディレクトリの再解析ポイントには再帰しません。検索ルートとして直接指定したパスは開きます。
- `dircount.exe`、`dirsize.exe`、`dirFind.exe`：ディレクトリのシンボリックリンクには再帰しません。ジャンクションなどの再解析ポイント全般を除外するものではありません。
